# TrainHotspot

A Progressive Web App that tells you, for your train trip in Italy, where you'll have mobile network and where you won't (long tunnels), and alerts you before you lose signal.

**App:** https://homohabilis.github.io/TrainHotspot/

## What it does

- **Plan a trip** by train number (Trenitalia and Trenord, looked up on [Transitous](https://transitous.org) from your browser) or by stations and times.
- **Trip outline:** a line of your trip in green (good network for at least 5 minutes), amber (short gaps) and red (probably no network: tunnels), with the percentage of the trip with coverage.
- **Coverage times:** the list of clock times when you'll have a good window, refreshed about once a minute from your GPS position, speed and delay.
- **Works offline** once the trip is loaded: the trip is stored on the device.
- **Position** from GPS snapped to the track, with dead reckoning (last speed, then timetable plus delay) when GPS is lost in tunnels.
- **Alerts** before entering a no-network zone and when network comes back: banner, sound and vibration in the foreground, system notifications while the browser keeps the page alive.
- **Settings:** good-window length (default 5 min), minimum tunnel length, margins, alert lead time.
- **Demo:** replay any trip at 60× speed to see the alerts.

## Languages and trip grade

The interface follows the phone or browser language: English, Italian, French, Spanish, Portuguese or German (English otherwise), and can be changed in Settings. Strings live in `app/js/i18n.js`.

Each trip gets a grade from A (best) to F. It starts from the share of the trip with network and lowers it when the network keeps dropping, using the typical uninterrupted stretch with network: 90% coverage with a drop every 10 minutes rates worse than 80% with one long gap. See `computeGrade` in `app/js/trip.js`.

## Background limits (no native app, no server)

| Platform | Works | Doesn't |
| --- | --- | --- |
| Any, screen on ("Keep screen on") | Everything | |
| Android Chrome, app in background | Notifications from the page's timers (throttled to about once a minute); position estimated from timetable + delay. Optional "keep running" uses an inaudible tone to stop Chrome freezing the page. | GPS while hidden; anything after Chrome discards the page |
| iPhone, installed on Home Screen | Everything while open | Anything while locked or in another app (iOS suspends web apps) |

Reliable background alerts need a native wrapper (e.g. Capacitor) with scheduled local notifications: see the feasibility study.

## Data

- Tracks, tunnels, line speeds and stations: © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors, ODbL 1.0. Built monthly by `.github/workflows/build-data.yml` (`tools/build_rail_data.py`) into `app/data/`.
- Train stops and times: [Transitous](https://transitous.org) API, called from the user's browser ([data sources](https://transitous.org/sources/); Trenitalia data via BusOne, non-commercial use only). ViaggiaTreno can't be used because it refuses browser requests from other sites. Italo is not covered.
- Coverage is estimated from tunnels only; valleys and rural gaps are not modelled yet.

## Development

Static files only, no build step: serve `app/` with any web server (`python3 -m http.server -d app`). The rail data in `app/data/` is generated by the data workflow.

Deployment: `.github/workflows/deploy-pages.yml` publishes `app/` to GitHub Pages on every push to `main`. In the repository settings, set **Pages → Source** to **GitHub Actions** once.

Tests (`.github/workflows/ci.yml`) run on every pull request commit and before every deploy, so a failing build is never published:

- `npm test`: unit tests of routing, trip timing, coverage, alerts, GPS tracking and station search (Node's built-in test runner, no install needed), including routing checks on the real rail data.
- `npm install && npx playwright install chromium && npm run test:e2e`: a headless browser smoke test that builds trips from stations and from a train number (timetable service mocked) and fails on any page error.
